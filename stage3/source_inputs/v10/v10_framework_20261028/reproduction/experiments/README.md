# 新物理基准上的最小控制闭环复算

本目录由原 `audit_new_materials/package/experiments` 的两个脚本复制后修改，原文件保持不变。它是两模态、无测量噪声、两个待估系数的人工误差测试，不是完整 CHNN 训练、硬件辨识或 KAM 认证。

## 运行

本目录控制脚本需要 Python 3 和 NumPy；上一级有限元重算脚本另需 SciPy。先由上一级 `reproduce_baseline.py` 生成 `new_baseline.json`，再在本目录执行：

```bash
python run_all.py
```

该命令严格按路线 A、路线 B、阻尼扫描、汇总检查的顺序运行，并将 BLAS 线程数设为 1。路线 B 读取本次路线 A 的结果，但重新生成共享训练数据和拟合值后逐项核对，没有复制旧的拟合值。

## 改了什么

所有物理缩放量 `NU,D,ELL,OMEGA0,E0,MU,B0` 均来自重新计算的有限元基准。基准阻尼设为 `alpha=0.05*omega0`，因此 `gamma=0.05`、第一模态阻尼比为 0.025。这是设计情景，未声称来自材料损耗测量。

所有训练与验证初值、路线 A 测试初值、路线 B 参考初值和跟踪初始偏差，都乘以原数值的 0.5，以降低新软梁的斜率。测试初值为 `[0.09,0.08,0.015,-0.01]`；路线 B 的额外偏差为 `[0.0045,0.004,0,0]`。这是新的实验设计，不是测得的运动幅值。人工势能残差系数仍为 `beta=0.2`。

主实验保留 `tau=20`、中点步长 0.001，以及原 RK4 参考步长 0.0005/0.00025、数据生成步长 0.0005、观测步长 0.002、积分窗 0.04、原拟合算法与控制律。增加的函数只记录参数来源、物理误差、运动域和控制输入域。

阻尼扫描使用 `zeta1=[0,0.01,0.025,0.05,0.1]`。每个情景重新生成四条训练轨迹和两条验证轨迹、重新拟合，再分别做路线 A 和路线 B 的无补偿、学习补偿、真实参数对照测试，时长 `tau=10`、中点步长 0.002。第二模态阻尼比是 `zeta1/nu2`，不是与第一模态相同。扫描不代表置信区间。零阻尼情景下，沿用的无约束最小二乘可能因数值误差返回极小的负 `gamma_hat`，不应解释为材料负阻尼。

## 结果文件和误差口径

- `minimal_control_results.json`：路线 A 对同一个保守耦合 `h0` 的恢复结果。
- `route_b_shared_results.json`：共享拟合、保守 `hhat` 预测，以及对冻结 `hhat` 轨迹的 PD 跟踪结果。
- `damping_sensitivity_results.json`：五个阻尼情景各自的拟合和两条路线短时结果。
- `control_audit_summary.json`：跨文件一致性检查、主要误差及所有实验的域极值。
- `minimal_control_loop.svg`：路线 A 误差曲线。

状态 RMS 为 `sqrt(mean_k ||z_k-zref_k||²)`，没有再除以四个相坐标。它是无量纲平衡坐标误差；另外给出由 `ELL` 和 `D` 映射得到的尖端位移误差及角度误差。

路线 B 同时给出与独立细步 RK4 参考的误差，以及与同一步长联合中点参考的同步误差。后者很小不能替代前者；两者的差异暴露中点相位误差。学习与真实参数对照结果近似相同，偶尔学习误差略低只是共有离散误差与微小拟合误差的相消，不能宣称超越真实参数控制。

输入核对覆盖存储端点和实际积分使用的相邻状态中点。总局部磁场按 `sqrt(B0**2+By**2)` 计算；另报局部梯度矩阵的谱范数，不能只报横向 `By` 而漏掉 30 mT 偏置场。端角和全梁斜率在数值时间点与 257 点空间网格上检查，未作连续时间区间认证。

所有输入仍是假设可独立指定的理想局部磁场/梯度端口；没有电磁线圈设计、饱和、标定、传感器噪声或高阶模态闭环验证。原参数下的冻结模态、拟合结果、长时数值结果及 KAM 量不能移植到新基准。

本轮最小控制测试没有执行能量 governor，也没有施加能量帽。初值的名义物理能量约 12.657 nJ，高于另行提出的 `0.95*Ec≈9.519 nJ` 充分条件。因此即使采样位移小于 4 mm，也不能把这些轨迹称为通过了该能量帽的安全保证。
