一、这份材料完成了什么

本包为原稿另建一套可以逐项解释来源的“文献参考+明确设计”的数值基准。
它不证明原稿旧参数原先来自本包新找到的文献，也不代表已经制造、采购或测量了实体导管。
旧参数L=.08 m、r=.0006 m、E=5 MPa、ρ=1100 kg/m³、μ=2e−5 A·m²、B0=.03 T及ζ=.025，已在原稿Supplement表3和上游reference_model_spec.json找到。原文将它们称为示例，而不是临床或航天器件实测。

本轮已完成：
1. 材料与磁芯的真实原始来源核查；为每个新输入标明文献参考、规格、设计或公式派生。
2. 含末端磁芯质量/转动惯量的Hermite有限元装配、16/32/64元频率收敛、独立连续梁边界特征根核验。
3. 重新生成两参数合成识别数据，重跑最小路线A与B，检验中点积分二阶、磁端口重构和参考解细化。
4. ζ1=0,.01,.025,.05,.1的独立重新拟合和短时控制敏感性；Br牌号范围、端惯性±10%、E±20%的模态敏感性。
5. 更新上传表的201条原稿记录，补齐此前未取得的补充材料，并另列70项新参数、派生量和条件预算。

未完成的内容保持明确标签：完整v10 CHNN训练、完整COMSOL复验、两模态相对全阶的非线性截断误差、区间KAM证书，以及新参数下的非零观测/执行误差能量证书。新基准不能继承旧证书或旧22.66 nJ能量帽。

二、新材料和几何

均匀实心圆梁L=80 mm、r=.6 mm是本研究保留的几何设计。Tong2025的实物半径也是.6 mm，但长度100 mm；只能支持尺度，不能冒充80 mm的直接取值来源。

材料采用Cho等2021对Sylgard 184A/184B的近似参考点：
E≈2.1 MPa，ρ≈1028 kg/m³，固化剂约占总混合物10 wt%（基料:固化剂约9:1），80°C固化2 h。
文献中E由拉伸试样测量，密度由比重天平测量；具体位置为Methods、Results前两段及Fig.1(a,b)，PDF第2–3页。
来源：https://doi.org/10.1002/bkcs.12352
开放全文：https://d-nb.info/1237384486/34
这些是近似材料参考值，不是目标圆梁的批次测试结果。E±20%只是设计敏感性，不是该文的置信区间。

三、磁芯与场

规定裸立方磁芯边长a=.250 mm。厂家存在相近外示尺寸的N50镍涂层微磁体，但本设计不把产品外尺寸当成已测磁芯尺寸。
N50牌号Br范围1.40–1.45 T；仿真取中点1.425 T。厂家密度表给≥7.5 g/cm³，本基准选7500 kg/m³为名义点。
来源：https://supermagnetman.com/pages/magnet-material-grades
尺寸尺度对照：https://supermagnetman.com/products/c0005-10
涂层说明：https://supermagnetman.com/pages/magnet-coating-specifications

使用名义工程近似μ≈Br a³/μ0，μ0≈4π×10⁻⁷ H/m。
公式来源：https://www.kjmagnetics.com/blog/magnetic-dipole-moment
推得μ≈1.77184214e−5 A·m²；裸芯质量mt=1.171875e−7 kg，过中心横向惯量Jt=1.220703125e−15 kg·m²。
Br上下端只产生磁矩范围[1.74075719e−5,1.80292709e−5] A·m²，不包含几何、温度、退磁和装配误差。
端惯性±10%是独立矩阵敏感性；减10%不代表同尺寸N50芯的规格内密度公差。
实际封装/镀层/胶/支架应计入质量和惯量；实际磁矩需要标定。基准假定磁芯质心与梁端重合，磁化方向沿参考切线。若偏移e≠0，必须加入惯性耦合。

偏置B0=30 mT、横向参考幅值6 mT和比较上限20 mT为设计。合成总模分别30.594 mT、36.056 mT。
Lussi2021使用的OctoMag报告任意方向最高40 mT总模；这是数量级依据，不证明本文两端口场/梯度、连续电流、误差和带宽同时可实现。
来源：https://doi.org/10.1002/advs.202101290 （§4 Magnetic Navigation；§2.4）
本轮最小闭环代码不含饱和分支，只报告控制请求与比较上限的关系。

四、阻尼、环境与实验设计

没有找到当前配方、几何、安装、频率和环境对应的实测ζ=.025。
新基准明确选择质量比例模型C=αM_total，并按含磁偏置和端惯性的第一模态定义ζ1=.025，因此α=2ζ1ω1=.3920004581 s⁻¹、γ=α/ω1=.05。
第二模态阻尼比因此约.004135，而不是所有模态都2.5%。α/2才是该线性模型的振幅衰减率。
ζ1=0用于保守参考；其余四点用于敏感性。Fischer2017的PDMS材料损耗数据仅解释为什么不能假定无耗散，不能直接变成当前梁的模态阻尼：
https://doi.org/10.1002/mame.201600526

模型为无重力、无接触、无外流的平面小斜率Euler–Bernoulli理论基准，忽略流体附加质量、梁分布转动惯量和剪切变形。它不表示体内或浸液装置已得到验证。
两模态用于最小算法链演示；全阶轨迹截断误差仍需另算。
β=.2是人为设置的非线性失配R*=βg，不是某项文献测得的20%材料误差。
训练、验证、路线A初态、路线B参考和初始扰动均较旧最小包缩为一半；目的是在较软的新梁上保持较小位移/斜率。具体数组保存在结果JSON与代码中。
最小辨识使用4条训练与2条独立验证轨迹、每条4τ（不是4秒），观测间隔.002τ、窗口.04τ；真值数据无状态噪声，存在数值积分残差。路线A/B主测试20τ≈2.5510 s，隐式中点步长.001τ，RK4参考步长.00025τ。所有误差定义见结果JSON。
路线B kp=1、kd=2是无量纲临界阻尼误差方程设计；不是物理材料阻尼。

六、能量和误差预算的边界

对于名义物理能量
E=T_total+(EI/2)∫w_ss² ds+μB0(1−cosθ)，
非负分项及夹持条件给||w||∞²≤2L³E/(3EI)。
净空c=4 mm时，新Ec=3EI c²/(2L³)≈10.0197171 nJ，条件预算.95Ec≈9.5187312 nJ。
若另行保证实际名义物理能量始终≤该预算，才推出中心线≤3.898718 mm；这不是当前闭环轨迹已获的认证。
本轮路线A初始名义能量约12.6567207 nJ，已经高于该预算；代码也没有governor。因此不能将本轮最小闭环结果作为能量帽保证。条件不满足不等于轨迹已越界。
含人工残差的任意“学习能量”不能自动替换进上述非负物理能量界。

原稿Table S12本来就将1 mrad、.01 rad/s、.1 mm/s、1%、.5 nN、.05 μT写为确定性误差假设，未称测得规格。
它们应继续作为条件预算或待验证的工程要求。举例：6 mT命令的1%乘性误差加.05 μT加性误差，合计包络60.05 μT，不是整个执行器具备.05 μT总精度。
硬件化仍需同批材料/动态衰减、磁矩与场梯度标定、状态估计和延迟的证据。这些不能靠给假设补一篇量级相近的引用来完成。

七、复现与文件

依赖：Python、NumPy、SciPy；环境版本写在new_baseline.json。
依次运行：
python reproduce_baseline.py
python experiments/minimal_control_loop.py
python experiments/route_b_shared_data.py
python experiments/damping_sensitivity.py

或者运行python run_all.py。
先A再B，B会重新生成共享拟合并与本次A核对，不读取旧稿拟合结果。
浮点结果会因平台略有差异；严格区间认证不在本包范围。参数数字保留较多位用于复现，不能把这些小数位理解成材料测量精度。
sources/保存来源审计和上游原示例配置；parameter_section.tex与parameter_sources.bib为可并入论文的新参数说明。正文其它数值表、图和证书必须在相应复算后才能更换。
