# 实际学习与三维共振结果：第五阶段 P1 的已完成部分

这组工作恢复了完整可训练复网络及旧理论链，并新增实际三维共振计算。它没有把学习性能、形式扭转或历史两模态证书包装为新的三维 KAM 证书。完整推导见 `../proofs/chnn_kam_restored.md`。S5-L01/R01–R04 的能量是原三维 ROM 的理想均匀轴向偏置 `H_ideal`；P0 完整线圈闭环为 `H_coil`。两者共享 12 配置/24 相空间、20 单元几何、变质量和正则尺度，但不是同一磁势。

## S5-L01：九次新训练，全部复隐藏权重参与

`program/learning_models.py` 直接导入第二阶段复网络与 SPD 网络；8749 参数机械解析字典是本轮新代码。训练/验证分别 1024/256 点，三种子 51001/51002/51003，每模型每种子 1200 次 Adam 更新、batch128。统一标量 Hamiltonian 与正确正则梯度损失。每50步只在验证集选 checkpoint，九个模型 SHA 全部冻结后，再生成独立512测试/256域外标签。`S5_L01_freeze_before_test.json`、训练曲线和九个 PT 权重均保存。无旧权重被重造。

|---|---:|---:|---:|---:|

二次先验测试场误差63.094%，历史较小48特征读出62.964%。这些相同数据、相同更新次数的比较没有匹配函数类、参数量、学习率或每步 FLOP；解析字典 lr=.001、两网络=.003，训练/验证计时预试后预定。不能隔离“复数比实数优越”，也不能声称多项式最优解仍有35%误差。详细时间、目标梯度、选中步数、参数实/虚变化见每个 `*_training.json`。

对每个模型另取固定8个测试+8个域外点检查 Hessian、条件数、沿负特征向量的能量二阶差分、Legendre 方程和真实动量误差。复网络测试样本最大条件数可达 `1.67e5`，SPD 本轮最大域外条件数约1811；本轮好于第二阶段压力域不意味着可以删除历史 `10^10–10^12` 病态证据。非正 Hessian、局部根求解失败/进展标记和域外误差完整保留。`S5_L01_independent_checks.json` 重新生成8个真实 ROM 标签、核对九个权重和训练源码 SHA，并独立确认所有保存的负曲率符号。

精确证据：`results/learning/S5_L01_protocol.json`、`S5_L01_results.json`、`S5_L01_metrics.csv`、`S5_L01_independent_checks.json`；训练/独立评估 NPZ、预测 NPZ、PNG/PDF 与日志同目录。训练总运行约410.8s，环境 Python3.12.14/Torch2.5.1+cpu、单线程；完整环境及时间以 JSON 为准。

## S5-L02：真实 full-coil 端口对学习残差的可达性

使用 S5-L01 的三个模型×三种子×八个独立状态，共72项。由 `δg=∇h_learn−∇h_true`，要求的场修正是 `(-δg_P,+δg_Q)`。实际电流只能改变动量方程，因此配置速度误差 `−δg_P` 不可被这个接口直接消除。对 `δg_Q` 使用 `G_coil(Q)` 做受限最小二乘，真实状态点有效秩均5（相对阈值1e−8），并保留正交不可达分量。

第一次23项 SLSQP 失败：伪逆要求电流很大，以它做暖启动先做无关电流投影导致不稳定。物理组修复为从已可行的上次电流进入**同一个广义力目标**，容差/限制未降低。旧 JSON/CSV/NPZ/日志保留为 `S5_L02_pre_warmfix_*`；新 `S5_L02_*` 实际72/72完成，17.417s，部分解达2A电流边界。场/梯度在真实磁求积点检查，不冒称整个工作空间界。

残差不会被人为设零：修正后/前总场误差比，解析字典0.8845–0.9898，复网络0.8959–0.9960，SPD0.8482–0.9965。保留的主要量还包括不可执行的配置速度项、力像外分量、限幅残差、求解器状态、原要求电流和实际电流。这个实验是声明0.25s电流变化窗口的静态状态点分配，不是学习补偿的真实闭环积分。P0 的 full-coil 闭环另有真实积分结果，但没有使用这些学习权重；不能拼接宣称学习闭环已验证。

## S5-R01–R04：共振及第一次可计算的正确正规形部分

- **R01，实际运行12.6s。** 完整三维 ROM 的四对1:1弯曲频率；三阶2600单项式无零除数，四阶17550单项式中206个共振项（128个非动作项）。正确轴向生成器 `A=S_q^(−1)R S_q` 的 Noether 量为 `P^TAQ`，有限点 Poisson 缺陷≤1.11e−15。仅 `H_ideal` 具有这里的对称性；完整线圈几何、流体与接触不能默认保留。
- **R02，当前正确版18.97s。** 计算第一对限制四阶正规形，三阶消元括号保留全部12个通道。原混合高阶 AD 错误版的所有文件另存 `S5_R02_forward_ad_failed_*`，其结果不采纳。当前全 reverse AD 置换缺陷2.27e−13，独立单标量四次导数通过，原四次系数与半径外推差7.26e−7。
- **R03，实际代数复算。** 原 `ξ0²χ1²` 系数−434.7256304，被跨模态三次修正+434.7190279显著抵消，留下−.00660249924。第一对限制写成 `A(I0+I1)²+B L²`，圆偏振坐标辛缺陷4.46e−16；形式twist特征值约 .00164488、.0264100，行列式4.34414e−5。只有部分四阶候选，不是完整12维twist或证书。
- **R04，独立执行1.21s。** 在32个新点独立验证圆偏振作用符号，最大作用恒等式误差8.67e−19。再在原第一对子空间取三组实际24维状态，外模态场范数分别 .01643/.06573/.26300，均非零。故不能把第一对限制正规形当成实际不变的两自由度机器人。该反例不排除经过正规化变换的近似子空间，但其不变性未证。

S5-R02 中四个外部扭转通道产生全部非零三阶括号修正；这是变量质量三维耦合必须保留的实例。仅检查原四次能量相位平均会得到约6.6万倍不同的共振系数。另三对弯曲共振及所有对间耦合尚未完成，解析尾项、域、twist逆界和所有小除数未认证。

## 复算入口与保存规则

使用学习环境和单线程：

```bash
export PYTHONDONTWRITEBYTECODE=1 OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1
PY=/workspace/1028-cloud/venvs/learning/bin/python
$PY stage5/program/learning_postprocess.py
$PY stage5/tests/test_learning_research.py
$PY stage5/program/resonance_verify_partial_scope.py
```

上述第一条重新检查冻结数据与权重；测试不改训练结果。完整再训练入口为 `run_learning_research.py --steps 1200`，它拒绝覆盖既有 S5-L01 protocol。若要从头再训练，应在新复制的工作目录中保留原结果并指定新的实验编号/输出目录；不能删除旧结果冒称同一次训练。`--evaluate-only` 是读取冻结权重的重新评估入口，会重写本目录派生指标，因此严谨重跑应使用复制目录。

独立复算共振可运行 `resonance_research.py`、`resonance_normalform_pair.py`、`resonance_reduce_pair.py`，依此顺序；不要运行名含 `forward_failed` 的拒绝版本作为当前算法。静态可达性入口 `learning_coil_reachability.py` 使用当前已修复的完整端口，读取冻结预测；同样建议复制结果目录后运行，以保留本次日志。统一测试入口由主 README 提供。
