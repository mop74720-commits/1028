# 第五阶段各程序共用的物理、坐标与证据约定

最终对象始终是微重力条件下血管内三维磁驱柔性介入机器人。第五阶段在已有三维杆的不同计算层之间建立实际接口，不把这些层声称为同一个已证明的模型。原始材料、第二至四阶段文件均为只读输入。

## 1. 同一个几何族与三个不同的物理分支

所有新 ROM 都直接复用 `stage3/source_inputs/starter/stage2/program/learning/rod_rom.py`。12个配置坐标是两个弯曲轴和扭转轴各四个应变 Ritz 系数；20/40/80是空间求积单元数，不能称作20/40/80个配置自由度。SO(3)标架、位置/角速度 Jacobian、平动及转动质量仍由实际几何计算。

固定正则尺度沿用 `q=Sq Q, p=Sp P, SqᵀSp=(E0/omega0)I, tau=omega0*t_seconds`。`Mbar(Q)=(omega0²/E0)SqᵀM(SqQ)Sq` 每次随位形重算。固定缩放的选取不要求新全线圈 Hamiltonian 在 q=0 仍处平衡，也不意味着旧线性频率就是全线圈平衡频率。

| 分支 | 实际 Hamiltonian/场 | 与其他分支的关系 |
|---|---|---|
| 原几何 ROM 的解析/学习分支 | `Hideal=T(Q,P)+Velastic(Q)+Vuniform(Q)`；合成光滑载荷另行声明 | 保留原学习数据定义、三维重复频率和输运基准；所有质量导数保留。这里的均匀理想偏置不能冒充完整线圈。 |
| 新完整线圈 ROM | `Hcoil=T+Velastic+Vcoil(Q,i)`；i是12个总电流 | 同一几何与质量，替换磁势。没有再叠加原理想偏置；同实际电流的仿射版本只作为模型误差对照。 |
| 高维 Cosserat | 中心线与材料标架的离散杆，含剪切/伸长，完整线圈、规定脉动流、刚性管腔、摩擦 | 共用材料/磁化/线圈与物理功率端口，配置空间并非12维ROM。主环境实验与另设的严格匹配保守ROM误差试验必须分表。 |

`H/E0` 的常数零点可以不同，比较能量变化时使用同一分支的初始值。状态范数是无量纲正则坐标误差；只有经几何重构后才报告米或毫米。论文不可把不同势、不同初态、不同参考场的成功曲线拼成同一算法的统一验证。

## 2. 磁能、实际力与反馈链式导数

每个磁化积分点采用同一偶极能 `−mu(Q)·B(r(Q),i)`；`B` 来自原圆线圈 Biot–Savart 求积，对i线性。故

`Vcoil/E0 = c(Q)ᵀi, Gcoil(Q)=−Dc(Q)ᵀ, Pdot_magnetic=Gcoil i`。

计算物理力时电流固定：先计算 `f(z,i)=J partial_z H(z,i)`，再代入控制 `i=k(z)`。真实闭环 Jacobian 是 `f_z+f_i Dk`。直接计算 `J grad_z H(z,k(z))` 会额外加入不属于该磁执行器力的项；冻结电流求 Jacobian 又会漏掉反馈项。两种错误都不能用于原（36）的非线性更新或结构判断。

`CoilROM` 的默认电流是预通电偏置分配，不是从零启动。受限分配和连续电流斜坡另有显式状态与时间约定；同一状态下的场/梯度约束只能证明固定空间采样点上的约束。移动磁点和连续工作域的保证需要额外检验，不能由一次分配成功自动推出。

## 3. 同一机械功率端口，分别记录能量

在无环境的ROM上，`Emech=T+Velastic`，其无量纲功率为 `H_PᵀGcoil i` 加其他明确载荷功率。固定偏置能量 `Hbias=Emech+Vcoil(Q,i_bias)` 的变化则由增量电流 `i−i_bias` 做功。若报告瞬时含时磁能 `Hcoil(z,i(t))`，总导数还必须含 `partial_i Hcoil·di/dtau`；不能混用三种能量。

理想共点电流反馈 `i=i_bias−kappa GcoilᵀH_P` 给 `Hbias' = −kappa ||GcoilᵀH_P||²`。这是实际磁端口的功率恒等式，既不授予12个模态独立施力，也不证明保持原K。SI功率端口为 `y_SI=E0*omega0*GcoilᵀH_P`（W/A），所以相同物理律的 `kappa_SI=kappa/(E0*omega0)`（A²/W）。ROM与Cosserat的控制转移使用这个转换，而非直接复制不同尺度下的数值增益。

约束投影、预计算前馈、采样和电流斜坡会改变实际输入。其真实功率、不可达残差和场约束分别记录；理想瞬时共点耗散不能直接套到受限采样控制。规定血流、移动基座/壁也可能向杆供能，机械能不是封闭系统守恒量。

## 4. 数值与证明层级

隐式残差包含完整原场及同一个未知中点上的实际输入。Central4只用于自治保守分支；比例动量阻尼的合法时变图只用于明确满足该形式的分支。非比例状态反馈的一般图需另构造Ku。

高阶输运允许对一形式作可计量的空间缓存，但原Hamiltonian、参考轨迹和原场残差仍调用完整变质量动力学。必须区分输运阶数、空间缓存、Moser辅助积分、图微分、原场表示、时间推进及非线性求解误差。结构匹配与原场准确性分别验收。

旧v10证明保持其原两模态/平面高维对象。新三维共振分析若使用Hideal，不能当作全线圈新平衡的KAM证书。真实微重力生理标定、柔性血管壁、双向FSI、统一ROM误差与完整三维KAM仍各有独立证明/实验责任。实际状态以 `repair_status.csv`、`inheritance_update.csv` 和每个实验的JSON为准。
