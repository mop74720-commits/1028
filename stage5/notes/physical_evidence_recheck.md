# 物理接口交叉核验与结果身份

本项是独立读取源码及原始数组后的核验，不是另一轮动力学积分。新增入口为
`program/verify_physical_evidence.py`，输出为 `results/physical_evidence_recheck.json`。
在 learning 环境实际执行通过，耗时约0.18秒：12项来源哈希、10条ROM轨迹
（原8条及分配器修复后的2条）、7条完整空间杆轨迹。

```bash
PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 \
  /workspace/1028-cloud/venvs/learning/bin/python \
  stage5/program/verify_physical_evidence.py
```

旧 `coil_rom.py` 和力分配器/runner 的快照与原结果记载的哈希一致；修复后的
力补偿结果与对应当前源码哈希一致。原失败的分配器批次和PyElastica接口失败
仍存在。没有以当前源码替换原运行版本，也没有重写原结果来匹配新源码。

核验直接由NPZ电流和时间重新计算ROM连续斜坡变化率，由杆的
`current_ramps.csv`端点重新计算实际电流幅值、变化率及接点连续性。10条ROM
电流均满足2A/20A每秒；7条杆的电流同样满足，接点缺陷为零。重新读取每个RK
阶段的真实磁点场记录以及杆保存时刻的真实节点梯度，均未发现主受限轨迹
的采样超限。这些检查不能提供未采样的时间/空间全域界。

杆的末端RMSE直接由 `r[:,-1]-target` 重新计算；接触、血流合力和机械能—功
残差由原始数组/CSV重新核对。全部非零新增共点增益均为
`95590.3224538941 A²/W`，与ROM的SI转换一致。主有流有壁轨迹的跟踪负结果、
时间细化观察阶0.469及空间观察阶1.007没有被改变。

需要保持两项细节，避免把正确数据读成更强结论：

1. **全步极值和保存快照极值不同。** 冻结 `rod3d/model.py` 在每个力求值累计
   接触最大值，但NPZ每2ms保存一次。窄管支路保存快照最大穿透为
   `61.555813 μm`、法向力 `11.350828 μN`；全步汇总为
   `61.603220 μm`、`11.352410 μN`。前者能由当前NPZ直接重算，后者依赖原
   实际积分中保存的累计值及源码，不能宣称二者逐位相同。独立检查器最初
   错误要求相等而失败，回读积分循环后将该断言修正为同采样CSV一致，并
   保留此失败说明；没有改变任何物理数据、积分精度或验收容差。
2. **完整线圈模型中继承的频谱字段是缩放来源。**
   `CoilROM.metadata()`从旧ROM继承的 `omega_rad_s`、`nu`、
   `repeated_frequency_pairs` 和旧 `KAM_status` 描述理想均匀轴向偏置分支。
   `ω0`作为坐标/时间尺度可继续使用，但这些数值不是重新求出的完整线圈
   平衡频谱。当前实际线圈在直杆处甚至不必平衡，不能把四对1:1结论或
   SO(2)对称性自动写给 `Hcoil`。新元数据解释在本核验JSON及
   `unified_model_contract.md`中明确，旧JSON不改写。

`program/coil_transport_check.py`已真实执行并保存
`results/coil/transport_interface_check.json/.log`：同一个完整20单元、256线积分点、
12总电流、无额外理想偏置的光滑共点场，在原solve动力学与高阶inv后端之间，
场差 `1.61e-16`，Jacobian差 `1.26e-13`，原始一阶齐次输运关系误差
`3.30e-17`。该证据覆盖物理场、低阶Jacobian和一阶接口，不能代替更高阶
张量、图匹配及积分实验。本检查器记录该历史运行和当前源码是否相同；
后续driver变动必须使用自己的新run来源记录。

最后，匹配ROM—杆的2ms固定偏置诊断在三种网格上均超出 `.03 T/m`，
最大约 `.798 T/m`。该诊断只比较共同输入下的模型响应，明确排除在约束合格
导航控制证据之外；没有用主受限实验的通过状态掩盖这一负结果。
